# Support

## Start here

For installation and normal usage, read the [Quick start](README.md#quick-start) and [agent workflows](docs/AGENT_WORKFLOWS.md).

## Bugs

Open a **Bug report** when the exporter, source pack, build, or fidelity workflow behaves incorrectly.

Include:

- Figma → Agent version;
- export scope and options;
- safe reproduction steps;
- relevant `manifest.json` errors;
- expected vs actual output.

Do not upload confidential client designs or source packs to public issues.

## Feature requests

Open a **Feature request** for improvements to fidelity, source-pack completeness, portability, agent workflows, validation, performance, or installation UX.

## Current development

Follow [#2 — v0.4: Proof & Validation](https://github.com/Ibrahim-3d/figma-to-agent/issues/2) for the current public workstream and [ROADMAP.md](ROADMAP.md) for the longer-term direction.

## Security

Potential vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public bug issue.
