# Figma → Agent v0.3.2

## Why this release matters

v0.3.2 makes the public release system itself trustworthy. Releases now require curated, user-facing notes instead of publishing raw pull-request summaries, so the release page becomes a reliable record of what changed, how to install it, and what comes next.

## What's new

- **Curated release notes are now mandatory.** CI will not publish a new version unless `docs/releases/v<version>.md` exists.
- **A documented release process** now defines versioning, release-note structure, validation, packaging, and post-release checks.
- **README public navigation is simplified** so project direction, support, security, releases, and contributing have one clear home.

## Improvements

- Release communication no longer depends on GitHub's autogenerated changelog as the primary narrative.
- The public version story now has an explicit compatibility and migration section for every release.
- Future releases are forced to connect back to the active roadmap/workstream.

## Install / update

1. Download `figma-to-agent-v0.3.2-sideload.zip` from this release.
2. Extract the archive.
3. In Figma Desktop, open **Plugins → Development → Import plugin from manifest…**.
4. Select the extracted `manifest.json`.
5. Run **Agent Source Exporter**.

For normal Figma → Agent work, keep **1× exact** reference renders enabled.

## Compatibility

No source-pack schema or extraction behavior changed in v0.3.2. Existing v0.3.x workflows remain compatible and no migration is required.

## Known limitations

- Large entire-file exports can still be memory-heavy.
- SVG candidate detection still includes heuristic behavior.
- Font binaries are not included in exported source packs.
- Static design evidence cannot define application behavior that is absent from the source design or target codebase.

## What's next

The next product workstream remains [v0.4 — Proof & Validation](https://github.com/Ibrahim-3d/figma-to-agent/issues/2), focused on reproducible benchmarks, source-pack validation/versioning, export robustness, and visual regression tooling.
